# HANA — вебсайт квіткового магазину

Курсовий проєкт: адаптивний сайт квіткового магазину з інтерактивним каталогом, кошиком,
оформленням замовлення та конструктором букетів.

**Стек:** Angular 22 (standalone-компоненти, signals), TypeScript, SCSS, Vitest.

## Запуск

```bash
npm install
npm start
```

Сайт відкриється на http://localhost:4200.

| Команда         | Що робить                                    |
| --------------- | -------------------------------------------- |
| `npm start`     | Dev-сервер з автоматичним перезавантаженням  |
| `npm test`      | Юніт-тести (Vitest)                          |
| `npm run build` | Production-збірка в `dist/hana`              |

## Сторінки

| Маршрут            | Сторінка                                                  |
| ------------------ | --------------------------------------------------------- |
| `/`                | Головна: банер, категорії, популярне, бренд, переваги     |
| `/catalog`         | Каталог: пошук, фільтри, сортування, «Показати ще»        |
| `/product/:id`     | Товар: галерея, розміри S/M/L, кількість, схожі букети    |
| `/bouquet-builder` | Покроковий конструктор букета з живим прев'ю та ціною     |
| `/favorites`       | Обране                                                    |
| `/cart`            | Кошик: кількість, промокод, доставка, підсумок            |
| `/checkout`        | Оформлення: дані покупця, доставка, оплата, валідація     |
| `/order-success`   | Підтвердження з номером замовлення                        |
| `/about`           | Про нас                                                   |
| `/contacts`        | Контакти, карта, форма зворотного зв'язку                 |

## Структура

```
src/app/
├── core/
│   ├── data/            # каталог товарів і опції конструктора
│   ├── models/          # інтерфейси Product, CartItem, Order, ілюстрації
│   ├── services/        # ProductService, CartService, FavoritesService, OrderService, ToastService
│   ├── catalog-query.ts # чисті функції пошуку, фільтрації та сортування
│   ├── bouquet-pricing.ts
│   └── validators.ts
├── shared/              # header, footer, product-card, bouquet-art, icon, quantity-stepper, toasts, uah.pipe
└── pages/               # сторінки (lazy-loading через app.routes.ts)
```

## Примітки

- Серверної частини немає: кошик, обране та останнє замовлення зберігаються в `localStorage`.
  Оформлення замовлення й онлайн-оплата лише імітуються.
- Букети намальовані векторно компонентом `BouquetArt` (SVG). Щоб показати справжнє фото,
  додайте файл у `public/` і вкажіть шлях у полі `image` товару в `core/data/products.ts`.
- Демонстраційні промокоди: `HANA10` (−10%), `SPRING15` (−15%).
