# Які фото потрібні сайту HANA

Кожне фото має ID. Файл називаємо `<ID>.jpg` і кладемо в `public/flowers/`. Коли знайдете фото, скажіть
мені ID (наприклад, «P03 — ось»), і я підключу його саме туди, куди треба.

Розмір: вертикальне фото, від 1200 px по короткій стороні. Фон світлий і чистий, без людей і написів.
Для кожного фото записано, чи потрібне пакування. Кольори пакування взяті з коду, щоб фото збігалося
з ілюстрацією, яка зараз стоїть замість нього.

## Додатково, не обов'язково

**Крупний план (`P01b`–`P17b`).** Картка товару має вкладку «Крупний план» зі збільшенням. Для неї
підійде те саме фото, обрізане ближче, тож окремо шукати не треба.

**Конструктор: окремі квіти (F01–F10).** Одна квітка або кілька на білому фоні, без пакування.

| ID | Квітка | ID | Квітка |
|---|---|---|---|
| F01 | троянда червона | F06 | тюльпан жовтий |
| F02 | троянда рожева | F07 | тюльпан рожевий |
| F03 | троянда біла | F08 | ромашка |
| F04 | троянда персикова | F09 | лаванда |
| F05 | півонія | F10 | евкаліпт |

**Пакування для конструктора (W1–W4, R1–R3).** Фото паперу: кремове, рожеве, бордове, крафт, плюс стрічки:
біла, пудрова, ягідна. Теж не обов'язково.

## Як підключаю фото

- Букети P: додаю в `products.ts` поле `image: 'flowers/P01.jpg'`. Тоді картка й сторінка товару
  показують фото, а SVG-ілюстрація лишається запасною.
- Категорії C: файли `bouquets`, `roses`, `tulips`, `peonies`, `seasonal`, `potted`. Я перейменую C1–C6 у ці імена.
- Банер H01: `hero.jpg`.
